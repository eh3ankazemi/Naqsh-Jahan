# Naqsh-e Jahan

Interactive 3D palace experience built with React, TanStack Start, and Three.js.

## Development

You need Node.js and npm or Bun installed.

```sh
git clone <this-repository-url>
cd <repository-name>
bun install
bun run dev
```

## Scripts

- `bun run dev` — start the local dev server
- `bun run build` — create a production build
- `bun run preview` — preview the production build

## Built with

- TanStack Start
- TypeScript
- React
- Vite
- Tailwind CSS
- Three.js
